# Asset provenance

`AppIcon.icns` is original programmatically drawn AppKit artwork generated by `scripts/generate-icon.swift` for Perch. Its source script is the editable authority. No external artwork or AI raster generation was used.

`Sounds/*.wav` are original PCM sound cues synthesized by `scripts/generate-sounds.py`. Each uses short tone envelopes and controlled peaks. No sampled recordings or external sound library was used.

The twenty feature glyphs are original resolution-independent SwiftUI paths in `Sources/Perch/WidgetGlyph.swift`, using a shared 24-point grid and rounded stroke. Secondary interface controls use Apple's system SF Symbols through AppKit/SwiftUI. The user's Vinz screenshots are design references only and are not included as application assets.

`Ambient/*.wav` are original 16-second procedural loops generated by `scripts/generate-ambient.py`: filtered noise and synthesized tones, with a crossfade at the loop boundary. They contain no field recordings or licensed music. macOS provides optional speech at runtime.

`docs/images/perch.svg` and the app icon share the same original bird geometry. The current app icon does not embed an SF Symbol. Earlier development releases used Apple’s system bird symbol; those icons were replaced before this public release.

`docs/images/relax.png` and `qr-code.png` are unedited captures of the native Perch 0.3.0 interface on September 7, 2026. The QR content is the synthetic example `https://example.com`; neither capture contains personal saved content.
