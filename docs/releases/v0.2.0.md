# Perch 0.2.0

Eight more tools for the dock: **Clipboard, Calculator, Converter, World clock, Countdowns, Habits, Breathing, and Keep awake**. There are now 14 widgets to choose from.

- Search the widget library or filter it to your current dock. Longer docks scroll while the grip and add button stay in place.
- Keep copied text when you choose, reuse recent calculations, convert six categories of units, and compare city times with a meeting preview.
- Track important dates and daily habits, take a short breathing pause, or keep your Mac awake for a set duration.
- New panels use your selected theme and accent, with matching vector icons.

Your existing dock layout and saved content stay in place. Add any of the new widgets with **+**. Format 1 data receives an exact migration backup before upgrading to format 2; older Perch builds refuse that newer format. The installer also backs up your data and previous app before replacement.

Use the same [install/update guide](https://github.com/606scat/perch/blob/main/docs/INSTALL.md) on either Mac. Requires macOS 14+ and access to this private repository. The universal package supports Apple Silicon and Intel; it remains development-signed and not notarized.
