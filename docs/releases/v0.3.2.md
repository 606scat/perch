# Perch 0.3.2

Fixes the square black corners that could show behind the rounded dock when it tucks into the screen edge. The native glass background now keeps its own matching rounded mask.

Widget layout, hover behavior, settings, and saved data are unchanged. Choose **Check for updates…** in Perch, or download **Perch.dmg**.

Signed with Developer ID and notarized by Apple. Requires macOS 14+. Includes Apple Silicon and Intel binaries.
