# Perch 0.1.0

First private release for macOS 14 and later, with Apple Silicon and Intel binaries.

- Compact dock for Focus, Today, Notes, File tray, Snippets, and Projects.
- Light, Dark, and System appearance; six accent colors with blue as default; optional glass backgrounds.
- Recordable shortcuts, menu-bar access, original sounds, and configurable dock motion.
- Shared install/update command with download verification, local backups, downgrade prevention, and saved-data preservation.

Install or update using [the instructions](https://github.com/606scat/perch/blob/main/docs/INSTALL.md). Your GitHub account needs access to this private repository.

This build uses an Apple Development certificate and is not notarized. macOS may require first-open approval. Apple Reminders and notifications require your own permissions. Promised-file drags without an existing local file URL are not yet supported.
