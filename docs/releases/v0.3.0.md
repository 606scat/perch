# Perch 0.3.0

Perch now has 20 widgets. New additions: Color picker, QR code, Text tools, Quick decisions, Doodle, and Tiny garden.

Relax adds five-minute guided breathwork or a quiet pause, with optional soft rain, ocean, warm tones, brown noise, and spoken guidance. Sounds are bundled with the app.

The picker puts everyday tools first. Dock tiles use short labels and counts, and your custom order stays intact. This release fixes a freeze when macOS delivers its day-change event in the background.

Download **Perch.dmg**, drag Perch to Applications, and use **Check for updates…** for future releases. Existing notes, settings, and widget data stay in their separate folder. Updates and format migrations keep local backups.

Signed with Developer ID and notarized by Apple.

Requires macOS 14+. Includes Apple Silicon and Intel binaries. [Installation and signing details](https://github.com/606scat/perch/blob/main/docs/INSTALL.md).
