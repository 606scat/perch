# Perch 0.3.1

Perch has 20 widgets for everyday work and small breaks, including five-minute guided breathwork with optional ambient sound and speech.

This patch corrects the optional installer’s recovery and first-open messages for the public notarized release. The app’s features and saved-data format are unchanged from 0.3.0.

Download **Perch.dmg** and drag Perch to Applications, or choose **Check for updates…** in Perch 0.3.0.

Signed with Developer ID and notarized by Apple. Requires macOS 14+. Includes Apple Silicon and Intel binaries. [Install and update](https://github.com/606scat/perch/blob/main/docs/INSTALL.md).
