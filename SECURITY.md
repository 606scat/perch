# Security reports

Please report vulnerabilities through [GitHub’s private vulnerability reporting](https://github.com/606scat/perch/security/advisories/new). Avoid putting credentials, personal data, or exploit details in public issues.

Include the Perch version, macOS version, reproduction steps, and expected impact. For an ordinary bug without sensitive details, use the issue tracker.

The latest released version is the supported version. Updates use signed Sparkle feeds and archives. A public-beta signing limitation is documented in [INSTALL.md](docs/INSTALL.md).
